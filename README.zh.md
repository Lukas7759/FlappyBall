# Flappy Ball – 更新说明

单文件浏览器游戏：`flapy.html`。直接用浏览器打开即可，无需安装。

## 更新内容

### 🌍 五种界面语言
波兰语、英语、俄语、中文和日语。

- 语言按钮（`PL`、`EN`、`RU`、`中文`、`日本語`）位于主菜单顶部。
- 首次启动时，游戏会选择浏览器的语言；如果不支持，则使用英语。
- 你选择的语言会被记住。
- 已翻译：菜单、难度及其说明、皮肤商店（含皮肤名称）、游戏结束界面、暂停、数据存储提示和隐藏结局文字。
- 手柄提示和管理员面板仍然只有英文。

### ⏸️ 暂停
- 按 **Esc** 或 **P**，点击左上角的 **⏸** 按钮，或切换浏览器标签页。
- 暂停时，音乐、管道移动以及护盾/自动驾驶的计时都会停止（以前暂停期间它们可能会走完）。
- 在暂停界面可以继续游戏或返回菜单。

### 🏆 “新纪录！”横幅
当你刷新最高分时，会显示在游戏结束界面上。

### 🐛 错误修复
- **管理员菜单不再在游戏进行中打开。** 以前快速点击鼠标（0.6 秒内点击 3 次）可能会意外打开它。
- **使用 `localStorage` 代替 Cookie 保存数据。** Chrome 不会为本地打开的文件（`file://`）保存 Cookie，因此进度可能丢失。旧的 Cookie 存档仍会被读取，所以不会丢失任何数据。
- 数据存储同意提示已与新的保存方式保持一致。
- 为中文和日文字符添加了备用字体。

## 存档键名

数据保存在浏览器的 `localStorage` 中：

`flappyBestScore`、`flappyTotalScore`、`flappySkin`、`flappyDifficulty`、`flappyCookieConsent`、`flappyMuted`、`flappyLang`

可以通过管理员菜单中的“Reset saved progress”清除（在菜单中连续点击三次，或用四根手指点按）。

## 第 2 版 – 关卡和新皮肤

### 🎚️ 5 个关卡（按单局得分计算）

| 关卡 | 起始分数 | 主题 |
|---|---|---|
| 1 | 0 | 白天 – 蓝天、绿色管道 |
| 2 | 200 | 日落 – 橙色天空、沙地、铜色管道 |
| 3 | 500 | 夜晚 – 星星、月亮、青绿色管道 |
| 4 | 800 | 宇宙 – 紫色星云、行星、霓虹管道 |
| 5 | 1100 | 结局 – 隐藏结局（以前在 200 分触发） |

进入新关卡时会出现“关卡 N – 名称”的横幅（已翻译成 5 种语言），画面也会立即切换。一局结束后，菜单会恢复为第 1 关的主题。

### 🎨 新皮肤（共 25 个）
新增 11 个：Lime（130 分）、Teal（150）、**Shadow – 黑球（167）**、Sunset（200）、Crimson（250）、Navy（300）、Mint（400）、Lava（500）、Bronze（650）、Emerald（800）和 Galaxy（1100）。皮肤按所有对局累计的总分解锁。

### 🛠️ 修复
- Diamond 皮肤后面缺少逗号导致语法错误，新增的皮肤无法加载。已修复。
- 第二个皮肤与第一个使用了相同的 `id: 'black'`，因此选择其中一个会同时选中两个。现在它有了独立的 `id: 'shadow'`。
- 当皮肤数量超过屏幕可显示范围时，皮肤商店现在可以滚动。
- 管理员菜单：新增“Jump to next level / ending”按钮，用于快速测试关卡。
